# Platform Risk Register (`docs/RISKS.md`)

**Last Updated:** 2026-11-26 (Phase 0)

| Risk ID | Category | Risk Description | Likelihood | Impact | Mitigation & Owner Policy |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **`R-001`** | **Legal / IP** | Sibling `D:\class-*` folders contain 374 proprietary **ALLEN®** PDFs with internal share watermarks, "SHOP NOW" ads, and 75 `/Encrypt` flags. Accidental ingestion exposes platform to copyright/trademark liability. | High (if unmanaged) | **CRITICAL** | Strictly quarantine `D:\class-*` outside `d:\go4guru`. Enforce `content_licenses` DB gates (`hosting_allowed`, `embedding_allowed`, `legal_review_status`) before any publish/RAG index. |
| **`R-002`** | **Data Quality** | External PDFs have mislabeled filenames (Class 9 SST files containing Class 6 Maths Ch 7), 9 binary duplicates, and broken `[cite_start]` / LaTeX rendering in Class 12 Maths exports. | Observed | **HIGH** | Never infer syllabus mapping from filename. Require SHA-256 deduplication, automated LaTeX/schema validation, and Academic Reviewer QA before publishing. |
| **`R-003`** | **Data Availability** | 0 `.xlsx`/`.xls`/`.csv` question banks currently exist in workspace; verified CBSE/JEE/NEET PYQ datasets are absent. | Observed | **HIGH** | Build schema-adaptive Excel staging importer; never fabricate fake PYQs (`is_pyq=true` blocked without provenance); request licensed/authored datasets from stakeholder. |
| **`R-004`** | **Legal / Child Safety** | Serving minors requires verifiable parental consent, data minimization, moderation, and compliance under India's DPDP Act & Rules. | High | **CRITICAL** | Implement age gate, parent consent table, PII stripping before LLM calls, parent raw-chat exclusion, and require qualified legal counsel sign-off prior to launch. |
| **`R-005`** | **AI Accuracy** | LLMs hallucinate algebra, signs, physics units, stoichiometry, and fake NCERT references. | High | **HIGH** | Mandatory SymPy/Pint/Chemistry deterministic verifier, hybrid rights-filtered RAG with citation validation, uncertainty fallback, and CI eval regression suite. |
| **`R-006`** | **Unit Economics** | Uncapped frontier LLM and ElevenLabs TTS calls can exceed student subscription revenue rapidly. | High | **HIGH** | Implement `provider_rate_cards`, deterministic Redis/DB quotas, S3 audio caching for static lessons, model routing, and budget circuit breakers. |
| **`R-007`** | **Whiteboard Licensing** | `tldraw` commercial SaaS usage requires paid licensing to remove watermark; switching later costs rework. | Medium | **MEDIUM** | Evaluate `tldraw` commercial terms vs MIT-licensed `Excalidraw` before Phase 4; isolate engine behind engine-agnostic `WhiteboardAction` schema. |
| **`R-008`** | **Multi-Tenant Security** | Missing `tenant_id` check on one endpoint leaks school/student records across institutions. | Medium | **CRITICAL** | Enforce tenant scope via shared repository base/PostgreSQL RLS + automated cross-tenant integration tests on every endpoint. |
| **`R-009`** | **Assessment Integrity** | Browser timer/score spoofing or network-drop double submissions corrupt exams. | Medium | **HIGH** | Server-authoritative UTC timer, backend-only scoring, `Idempotency-Key` submission, and local draft recovery buffer. |
| **`R-010`** | **Local Dev Infra** | Host Windows lacks Docker, Redis, and pgvector extension in PG 18 (`WSL2 Ubuntu` is available). | Observed | **MEDIUM** | Decide between installing Docker Desktop vs running Redis + pgvector in WSL2 Ubuntu before Phase 1/3 coding begins. |
